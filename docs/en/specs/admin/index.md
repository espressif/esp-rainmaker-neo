# Overview

Everything an admin or super admin can access in ESP RainMaker Neo: what the dashboard
currently exposes, the plane behind it, and what can be added.

Read the pages below in order for a full picture of the admin plane, or jump
straight to the one you need:

- [Authentication and Permissions](authentication.md) — how an admin session is
  established, and the `AdminDeviceUsersRole` IAM permissions it carries.
- [Admin APIs](apis.md) — the admin lambda endpoints, plus the regular user APIs
  an admin may call.
- [Data Model](data-model.md) — the tables and entities the admin plane reads
  and writes.
- [RBAC and Authorization](rbac.md) — how an admin request is authorized.
- [Dashboard](dashboard.md) — what the dashboard exposes today, and the
  expansion opportunities.
- [Fleet Indexing and Shadow Access](fleet-indexing.md) — querying the fleet and
  reaching node shadows.
- [Data Population](data-population.md) — how the data behind all of the above
  gets there.

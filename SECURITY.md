# Security Policy

## Reporting a Vulnerability

Security is an important part of ESP RainMaker Neo, and we welcome responsible reports from the security community.

Please **do not create a public GitHub issue** for a suspected security vulnerability. Instead, report it privately by emailing:

**esp-rainmaker-support@espressif.com**

Please include:

* A description of the vulnerability and its potential impact
* Steps to reproduce the issue or a proof of concept
* The affected release, version, or commit
* Any suggested remediation, if available

We will acknowledge the report, keep you informed while we investigate and address the issue, and credit you in the resulting advisory unless you prefer to remain anonymous. Please allow a reasonable period for a fix to be developed and released before any public disclosure.

## Bug Bounty Program

ESP RainMaker Neo is not currently included in the Espressif Bug Bounty Program. We plan to bring the project under the program as it progresses toward broader availability.

Until then, responsible vulnerability reports remain highly valued. Espressif may, at its discretion, offer an appropriate reward for significant security disclosures based on factors such as severity, impact, report quality, and novelty.

These reports will help us further strengthen the platform ahead of its formal inclusion in the Bug Bounty Program.

## Supported Versions

Security fixes are applied to the latest released version and the `main` branch. Users are encouraged to keep their deployments updated to the latest available release.
